# Asset provenance

This inventory records the origin and licensing treatment of assets distributed
with NoteM. Update it whenever a bundled asset is added or replaced.

## Project artwork

| Asset                   | Provenance                                                                                                                                                                   | License treatment      |
| ----------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------- |
| `assets/notem-icon.svg` | Project-original NoteM wordmark source created for the maintainer using Codex and first committed with the application; ownership confirmed by the maintainer on 2026-08-01. | MIT, as part of NoteM. |
| `src-tauri/icons/`      | Platform icon renditions generated from `assets/notem-icon.svg` with the Tauri icon tool.                                                                                    | MIT, as part of NoteM. |

The SVG is the source of truth for the application mark. Regenerate platform
icons with `pnpm tauri icon assets/notem-icon.svg`; do not hand-edit the raster
and platform-specific outputs.

The maintainer has confirmed that the project owns the NoteM SVG and may
distribute it under the project license. Git history establishes when the asset
entered the project; this document records the separate ownership confirmation.

## Interface glyphs

Inline SVG interface glyphs under `src/lib/components/` include adapted Feather
Icons geometry. Feather Icons is MIT licensed by Cole Bemis. The retained
license is included in `THIRD_PARTY_NOTICES.md`. NoteM-specific alterations and
new glyphs are distributed under NoteM's MIT license without removing the
upstream attribution.

## PDF viewer resources

The production build copies PDF.js resources from the exactly locked
`pdfjs-dist` package: CMaps, ICC profiles, viewer images, standard fonts, and
WASM components, including QuickJS. Their Apache-2.0, BSD-style, CC0-1.0, SIL
OFL-1.1, and MIT terms are reproduced in `THIRD_PARTY_NOTICES.md`.

## Spellcheck dictionary

The production build copies `index.aff` and `index.dic` from the exactly locked
`dictionary-en` package. Its complete SCOWL and incorporated-source notices are
reproduced in `THIRD_PARTY_NOTICES.md`.

## Test fixtures

The PDFs under `src-tauri/tests/fixtures/vault/attachments/pdf-fixtures/` are
generated by `scripts/generate-pdf-fixtures.py`. The Unicode fixture embeds
`LiberationSans-Regular.ttf` from the locked `pdfjs-dist` package; the font is
SIL OFL-1.1 licensed. The generator deliberately rejects missing font input and
does not search system font directories.

The fixture generator uses pinned ReportLab and pypdf development tools. These
tools are not bundled with the application.
